WALL PIPE - a retro pipe-laying puzzle (homage to Soleau Software's 1993 DOS game)

Play now:   open wallpipe.html (or index.html) in any browser - works straight from a file.
Install:    host this folder on any HTTPS static host, open index.html on your phone, then
            iPhone/iPad (Safari): Share -> Add to Home Screen
            Android (Chrome):     menu -> Install app / Add to Home screen
            After the first visit it works offline.
Controls:   tap/click a wall square to lay the NOW pipe (tap a dry pipe to swap it, -50).
            F = flow now (double points)   P = pause   M = sound on/off
